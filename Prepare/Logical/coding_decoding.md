# 16. Sentence Coding

Instead of coding individual letters,

entire words are assigned codes.

Your task is to identify which code represents which word.

---

## Example

If

```
"Good Morning"

is written as

"RA KI"

and

"Good Evening"

is written as

"RA LO"
```

Question

What is the code for

Good?

### Solution

Common Word

↓

Good

Common Code

↓

RA

Answer

Good = RA

---

## Example 2

```
"The Sky is Blue"

↓

AB CD EF GH

"The Water is Cold"

↓

AB IJ EF KL
```

Common word

↓

The

Common code

↓

AB

Another common word

↓

is

Common code

↓

EF

---

## Shortcut

Find

Common Word

↓

Common Code
